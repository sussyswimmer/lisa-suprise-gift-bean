# Bean v0.1.0-test.21 — Claude chat sync and new animations
Download the DMG matching your Mac: **aarch64** for Apple Silicon (M1 and newer), or **x64** for Intel. Requires macOS 14 or later. Quit the previous Bean before replacing it.

## Chat sync fixes
- Bean now notices Claude Desktop opening or restarting after Bean started (for example after a Claude update). Before, Bean could stay disconnected until it was restarted.
- When Claude asks for permission to use a tool, Bean now shows that Claude needs you instead of "working". A Claude Code session waiting for permission is no longer hidden by other activity.
- Chat titles that start with words like "Stop" or "Approve" no longer confuse Bean.
- Bean keeps following Claude Desktop chats while Claude Code is open. Interrupting Claude Code with Esc no longer stops Chat updates until Bean restarts.
- Long conversations no longer hide Claude's reply status: Bean reads the area around the message box first, and a partial read no longer counts as "finished".
- Buttons such as an extended-thinking toggle or dictation "Stop" no longer make Bean think Claude is working.
- If Bean's background watcher stops, Bean restarts it automatically.
- Connecting waits for Claude's window to become readable instead of failing on the first try.
- **Reset permission**: new test builds are signed differently, so macOS can keep showing Bean as allowed while blocking it. If that happens, use Reset permission in Bean's settings or setup screen, then allow Bean again.

## New animations
- Bean is now fully animated, frame by frame: she breathes and blinks while idle, types with both paws while Claude works, jumps when a reply is ready, bounces when Claude needs you, and naps while waiting for Claude.
- Bean gallops over to her laptop when Claude starts working.
- Between tasks she runs zoomies, trots around, chases her tail, stretches, and sniffs, alongside peeking, hopping, and boba breaks.
- "Reply is ready!" stays on screen for a few seconds, with a longer celebration.

## Always with you
- Bean now follows you across every desktop and over full-screen apps, so she stays in view when you swipe between Spaces. She lives in the menu bar and no longer takes a spot in the Dock.
- New **Speech bubble size** setting (Settings → Appearance): make the boxes above Bean's head Small, Medium, or Large.
- Bean's bubble now shows the name of the chat Claude is working on. With several chats or Claude Code sessions running at once, each gets its own line, with the ones that need you first.
- **Save Diagnostics to Desktop** in Bean's menu bar menu saves what Bean can read from Claude's window (button names only, never your messages), to help fix sync problems.

## Install
These are ad-hoc signed test builds, not Apple-notarized releases. On first launch, macOS may require Control-click → Open, or **Open Anyway** in Privacy & Security. Allow Bean Accessibility access when connecting. Checksums for the downloads are attached.
